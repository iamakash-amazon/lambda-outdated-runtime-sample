# Baseline Infrastructure Exemption

Scope: Ruby Lambda code in `apps/billing-ruby32/` (Gemfile, no Gemfile.lock) and
`src/ruby/handler.rb`. Both are standalone AWS Lambda handlers with no framework.

## Services Unavailable
- None required. The exemption exists because there is **no test suite**: there is no
  `spec/` or `test/` directory and no rspec/minitest in the Gemfile. This was already
  true before the upgrade.

## Fallbacks Attempted
- SQLite fallback: not applicable (no database).
- MockRedis: not applicable (no Redis).
- Substitute baseline: smoke-invoked each handler on the SOURCE Ruby
  (ruby 3.2.2, built from source) with `-W:deprecated`:
  - `apps/billing-ruby32/lambda_function.rb` `handler(event: nil, context: nil)` returned
    statusCode 200, total "19.99", CSV `id,amount,currency\ninv-1,19.99,USD\n`.
    A 2-invoice event (1.10 + 2.25 EUR) returned total "3.35". No warnings.
  - `src/ruby/handler.rb` returned `{statusCode: 200, body: "ok"}`. No warnings.
- The original code was also run on Ruby 4.0.9. It printed
  `lambda_function.rb:30: warning: literal string will be frozen in the future`
  (chilled string mutation via `label <<`).

## Test Fidelity Impact
- No unit tests. Validation relies on the smoke invocations above, a `ruby -c` syntax check,
  and RuboCop.

## Residual Risk
- Only the code paths exercised by the smoke events are verified.
